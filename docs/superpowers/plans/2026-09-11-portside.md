# Portside Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild StackBricks as Portside, a Tauri desktop app that runs versioned local MySQL, MariaDB, Postgres, and Redis/Valkey instances via containers.

**Architecture:** Tauri v2 app. React+Vite+TS frontend calls Rust Tauri commands. Rust owns Docker/Podman access (bollard), instance state (rusqlite), version catalog (JSON), and schema queries (sqlx + redis crate).

**Tech Stack:** Tauri 2, React 18 + Vite 6 + TypeScript 5, Rust 1.77+, bollard 0.18, sqlx 0.8 (mysql, postgres, runtime-tokio), redis 0.27, rusqlite 0.32, vitest.

**Spec:** Waived by user in chat on 2026-09-11. Decisions captured here: approach A (Tauri), engines = original 4 only, Docker-first with Podman compat socket, Windows/macOS/Linux day one, parity features + schema management (MySQL/MariaDB = databases, Postgres = databases + schemas, Redis = DB index counts + flush).

## Global Constraints

- OS targets: Windows 10+, macOS 13+, Linux (AppImage) from v1.
- Container runtime: Docker Desktop required; Podman supported free via Docker-compat socket, no separate code path.
- Data persistence: one Docker named volume per instance `portside-<id>-data`, never auto-deleted.
- Container name: `portside-<id>`, labels `app=portside`, `portside.id=<id>`.
- Default ports by engine: MySQL/MariaDB 3306 base, Postgres 5432 base, Redis 6379 base; auto-suggest next free port on clash.
- Version catalog tags (official Docker Hub only): mysql `8.4, 9.7, 26.7`; mariadb `11.4, 11.8, 12.3`; postgres `16, 17`; redis `7, 8`; valkey `8`.
- All fallible Rust commands return `Result<T, String>` with human-readable message.
- TDD for every task; commit after each green step sequence.

```rust
// src-tauri/src/docker.rs
use bollard::Docker;
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Instance {
    pub id: String,
    pub engine: String,
    pub tag: String,
    pub port: u16,
    pub container: String,
    pub volume: String,
    pub status: String,
}

impl Instance {
    pub fn new(id: &str, engine: &str, tag: &str, port: u16) -> Self {
        Self {
            id: id.to_string(),
            engine: engine.to_string(),
            tag: tag.to_string(),
            port,
            container: format!("portside-{id}"),
            volume: format!("portside-{id}-data"),
            status: "created".to_string(),
        }
    }
}

pub fn connect() -> Result<Docker, String> {
    if let Ok(host) = std::env::var("DOCKER_HOST") {
        return Docker::connect_with_http(&host, 5).map_err(|e| format!("Docker connect failed ({host}): {e}"));
    }
    #[cfg(windows)]
    {
        Docker::connect_with_named_pipe("//./pipe/docker_engine", 5)
            .or_else(|_| Docker::connect_with_http("tcp://127.0.0.1:2375", 5))
            .map_err(|e| format!("Docker not reachable. Is Docker Desktop running? {e}"))
    }
    #[cfg(not(windows))]
    {
        Docker::connect_with_socket_defaults()
            .map_err(|e| format!("Docker not reachable. Is Docker Desktop/Podman running? {e}"))
    }
}

#[tauri::command]
pub async fn detect_runtime() -> Result<String, String> {
    let docker = connect()?;
    let ver = docker.version().await.map_err(|e| format!("Docker ping failed: {e}"))?;
    Ok(format!(
        "runtime ok (docker {}, api {})",
        ver.version.unwrap_or_default(),
        ver.api_version.unwrap_or_default()
    ))
}
```

```rust
// src-tauri/src/catalog.rs
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct CatalogEntry {
    pub engine: String,
    pub tag: String,
    pub image: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Catalog {
    pub entries: Vec<CatalogEntry>,
}

pub fn bundled_catalog() -> Catalog {
    let raw = include_str!("../../src/catalog.json");
    serde_json::from_str(raw).expect("bundled catalog.json must parse")
}

#[tauri::command]
pub fn get_catalog() -> Result<Catalog, String> {
    Ok(bundled_catalog())
}

pub fn base_port(engine: &str) -> u16 {
    match engine {
        "postgres" => 5432,
        "redis" | "valkey" => 6379,
        _ => 3306,
    }
}

#[tauri::command]
pub fn suggest_port(engine: String, taken: Vec<u16>) -> Result<u16, String> {
    let mut p = base_port(&engine);
    while taken.contains(&p) {
        p += 1;
        if p > 65530 {
            return Err("no free ports".to_string());
        }
    }
    Ok(p)
}
```

```rust
// src-tauri/src/schemas.rs
pub fn mysql_url(host: &str, port: u16, db: &str) -> String {
    format!("mysql://root@{host}:{port}/{db}")
}
pub fn pg_url(host: &str, port: u16, db: &str) -> String {
    format!("postgres://postgres@{host}:{port}/{db}")
}

#[tauri::command]
pub async fn list_databases(id: String) -> Result<Vec<String>, String> {
    let inst = crate::state::load_instance(&id)?;
    match inst.engine.as_str() {
        "mysql" | "mariadb" => {
            let pool = sqlx::MySqlPool::connect(&mysql_url("127.0.0.1", inst.port, "mysql"))
                .await.map_err(|e| e.to_string())?;
            let rows: Vec<(String,)> =
                sqlx::query_as("SHOW DATABASES").fetch_all(&pool).await.map_err(|e| e.to_string())?;
            Ok(rows.into_iter().map(|r| r.0)
                .filter(|n| !["information_schema", "performance_schema", "sys", "mysql"].contains(&n.as_str()))
                .collect())
        }
        "postgres" => {
            let pool = sqlx::PgPool::connect(&pg_url("127.0.0.1", inst.port, "postgres"))
                .await.map_err(|e| e.to_string())?;
            let rows: Vec<(String,)> = sqlx::query_as(
                "SELECT datname FROM pg_database WHERE datistemplate = false ORDER BY 1",
            ).fetch_all(&pool).await.map_err(|e| e.to_string())?;
            Ok(rows.into_iter().map(|r| r.0))
        }
        "redis" | "valkey" => {
            let client = redis::Client::open(format!("redis://127.0.0.1:{}/", inst.port))
                .map_err(|e| e.to_string())?;
            let mut con = client.get_multiplexed_async_connection().await.map_err(|e| e.to_string())?;
            let n: usize = redis::cmd("DBSIZE").query_async(&mut con).await.map_err(|e| e.to_string())?;
            Ok(vec![format!("default ({} keys)", n)])
        }
        other => Err(format!("unsupported engine {other}")),
    }
}

#[tauri::command]
pub async fn create_database(id: String, name: String) -> Result<(), String> {
    if !name.chars().all(|c| c.is_alphanumeric() || c == '_') || name.is_empty() {
        return Err("name must be [a-zA-Z0-9_]+".to_string());
    }
    let inst = crate::state::load_instance(&id)?;
    match inst.engine.as_str() {
        "mysql" | "mariadb" => {
            let pool = sqlx::MySqlPool::connect(&mysql_url("127.0.0.1", inst.port, "mysql"))
                .await.map_err(|e| e.to_string())?;
            sqlx::query(&format!("CREATE DATABASE `{name}`"))
                .execute(&pool).await.map_err(|e| e.to_string())?;
            Ok(())
        }
        "postgres" => {
            let pool = sqlx::PgPool::connect(&pg_url("127.0.0.1", inst.port, "postgres"))
                .await.map_err(|e| e.to_string())?;
            sqlx::query(&format!("CREATE DATABASE \"{name}\""))
                .execute(&pool).await.map_err(|e| e.to_string())?;
            Ok(())
        }
        _ => Err("create_database is SQL-only; redis has no schemas".to_string()),
    }
}
```

`drop_database` mirrors create with `DROP DATABASE`. `list_schemas` queries `information_schema.schemata` for postgres, errors otherwise. Register all in `main.rs`.

```ts
import { invoke } from "@tauri-apps/api/core";
export type Instance = { id: string; engine: string; tag: string; port: number; status: string };
export const api = {
  list: () => invoke<Instance[]>("list_instances"),
  create: (engine: string, tag: string, port: number) =>
    invoke<Instance>("create_instance", { engine, tag, port }),
  start: (id: string) => invoke<void>("start_instance", { id }),
  stop: (id: string) => invoke<void>("stop_instance", { id }),
  remove: (id: string, wipeData: boolean) => invoke<void>("remove_instance", { id, wipeData }),
  databases: (id: string) => invoke<string[]>("list_databases", { id }),
  createDb: (id: string, name: string) => invoke<void>("create_database", { id, name }),
  dropDb: (id: string, name: string) => invoke<void>("drop_database", { id, name }),
  connectString: (i: Instance) =>
    i.engine === "postgres"
      ? `postgres://postgres@127.0.0.1:${i.port}/postgres`
      : i.engine === "redis" || i.engine === "valkey"
        ? `redis://127.0.0.1:${i.port}/0`
        : `mysql://root@127.0.0.1:${i.port}/mysql`,
};
```

```rust
pub struct Health { pub container_running: bool, pub tcp_open: bool, pub query_ok: bool }
impl Health {
    pub fn is_healthy(&self) -> bool { self.container_running && self.tcp_open && self.query_ok }
}

#[tauri::command]
pub async fn container_logs(id: String, tail: usize) -> Result<String, String> {
    let inst = crate::state::load_instance(&id)?;
    let docker = crate::docker::connect()?;
    let opts = bollard::container::LogsOptions::<String> {
        tail: &tail.to_string(), stdout: true, stderr: true, ..Default::default()
    };
    use futures_util::TryStreamExt;
    let mut s = docker.logs(&inst.container, Some(opts)).try_collect::<Vec<_>>().await
        .map_err(|e| e.to_string())?;
    Ok(s.join(""))
}
```
